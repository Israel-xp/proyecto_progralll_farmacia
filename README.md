# Farmacia San Benito - Backend y Asistente IA

Sistema web completo desarrollado en Flask, SQLAlchemy y Google Gemini.

## Instrucciones de ejecucion:
1. Activar entorno virtual: .\venv\Scripts\activate
2. Instalar dependencias: pip install -r requirements.txt
3. Configurar API Key: $env:GEMINI_API_KEY='TU_API_KEY'
4. Ejecutar el servidor: python main.py

## Servicios y Persistencia:
- Catalogo de medicamentos, registro de ventas y Asistente IA operativos.
